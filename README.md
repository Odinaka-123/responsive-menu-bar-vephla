# Responsive Navigation Bar

A clean and modern **responsive navigation bar** built with **pure HTML and CSS**.  
This project focuses on layout structure, responsiveness, and clean UI behavior across **desktop, tablet, and mobile devices** — without using any JavaScript or frameworks.

## ✨ Features
- Fully responsive across all screen sizes
- Clean desktop layout
- Optimized tablet layout (balanced spacing)
- Mobile-friendly stacked navigation
- Pure HTML & CSS (no JavaScript)
- Modern UI inspired by real-world products

## 🛠️ Technologies Used

## 🚀 Getting Started

### 1️⃣ Clone the repository
```bash
git clone https://github.com/Odinaka-123/responsive-menu-bar-vephla.git
```

2️⃣ Open the project
cd responsive-menu-bar-vephla

3️⃣ Run locally

Open index.html in your browser.

📱 Responsive Breakpoints

Desktop: ≥ 1024px

Tablet: ≤ 1024px

Mobile: ≤ 768px

Small Mobile: ≤ 480px
